# Symbole et Neutralité

Première version du site statique de l'association **Symbole et Neutralité**, en français.

## Pages

- **Accueil** — présentation de l'association et de sa mission
- **Publications** — espace destiné aux analyses et ressources
- **Contact** — coordonnées et formulaire de démonstration

## Technique

- HTML5 / CSS3 uniquement
- Aucun framework
- Aucune dépendance externe
- Conçu pour être hébergé avec **GitHub Pages**
- Mise en page responsive pour ordinateur, tablette et mobile

## Structure

```
index.html
publications.html
contact.html
style.css
```

Le contenu et les coordonnées sont volontairement provisoires pour cette première maquette.
